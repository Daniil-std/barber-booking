# Barber Booking Platform

Personal full-stack project built with Django, React and PostgreSQL.

## What I built

- Customer accounts and appointment history
- Service, barber and available-time selection
- Booking and cancellation
- Staff schedules, breaks and days off through Django Admin
- EN/PL interface for desktop and mobile

## Tech

Python, Django REST Framework, PostgreSQL, React, TypeScript, Vite, Docker, Gunicorn, WhiteNoise, GitHub Actions.

## Highlights

- Database constraints and ordered locks prevent overlapping reservations.
- Training bookings reserve a trainee and Senior supervisor together.
- Saved prices and durations stay unchanged after catalog updates.
- 44 backend tests and 7 frontend tests passed locally.
